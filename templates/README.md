# 模板选择

模板是信息提醒，可删除不适用章节、合并记录或使用等价的任务工具。先选择最小充分载体，不要求填写所有字段或登记文档等级。统一方法见 [流程](../docs/WORKFLOW.md#约定与文档选择)。

| 模板 | 何时有帮助 |
|---|---|
| [TASK](TASK.md) | 小改动；可直接放任务卡或 PR，不必另建文件 |
| [SPEC](SPEC.md) | 一份文档能说清需求、Context、设计、验证与结果 |
| [PRD](PRD.md) | 需求需要独立维护或跨方协作 |
| [SDD](SDD.md) | 关键设计需独立维护；必要时按子系统/端拆分 |
| [TEST-PLAN](TEST-PLAN.md) | 验证策略、资源与协作需独立安排 |
| [DELIVERY](DELIVERY.md) | 已拆分复杂文档时，集中汇总实际交付结果 |
| [ADR](ADR.md) | 重大、长期或难逆的选择及其理由 |
| [PROJECT-RULES](PROJECT-RULES.md) | 项目接入时补充实际命令、边界和团队要求 |

复杂任务也不必机械创建完整文件包。某个内容已经由任务系统、CI 或接口定义维护时直接引用。默认占位文字不是事实或批准，复制后删除无用提示，不把空表当交付。
