# 新任务启动提示词

复制下面内容交给 AI，删除不适用的提示文字并填写括号内容。

```text
请按照项目中的 AGENTS.md 和 AI-PLAYBOOK.md 处理此任务。

项目或代码位置：<路径、仓库或已上传材料>
原始需求：<按原意填写，不必先改写成专业术语>
期望结果：<分析 / 设计 / 实现 / 评审 / 修复并验证>
已知成功标准：<没有时写“待梳理”>
明确不做：<没有时写“待梳理”>
约束：<时间、兼容、安全、平台、存储、不可修改区域等>
允许的操作：<只读检查 / 允许修改代码 / 允许运行测试等>

先检查工程和已有文档，不要询问能够从工程发现的问题，也不要立即生成全部模板。

首次有效输出按 AI-PLAYBOOK 第 4 节随任务精简：说明文档等级、验证档位及理由，简述改什么、如何验收、Ready 结论与下一步。
有真实假设、阻断、风险或需要我决定的问题时必须说明；复杂任务按需展开工程证据与行为拆解。已有文档直接引用，不重复输出全部字段或空表。

如果没有关键决策缺失，并且我已授权实现，请继续推进必要的 Build、实现和验证；不要为了等待形式确认而停止。
```
