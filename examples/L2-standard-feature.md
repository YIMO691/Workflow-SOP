# 示例 SPEC：收藏项目

这是教学设计与交付说明示例，没有真实执行测试。所有背景为示例假设；实际项目应替换为检查过的来源。本例展示澄清、行为切片和验收怎样放在同一份 SPEC。

## 来源与 Context

示例需求：用户希望在项目列表中快速找到常用项目。假设已有用户登录和项目可见性校验，但没有收藏记录。沿用现有权限模型，不改变项目授权；账户从可信会话取得，不能信任客户端自行指定账户。

## 澄清与决定

先查登录、权限与持久化能力，再决定用户行为。教学情境中约定：仅在线收藏，不支持离线修改；“取消收藏”指目标收藏关系不存在，“停止等待”只表示客户端不继续等待请求。服务端保存后丢失响应时，停止等待不保证撤销；因此不继续讨论范围外的离线合并策略，也不把按钮恢复旧样式当成远端回滚。

这些是示例约定，不是实际用户批准记录。真实需求若不同，修订对应验收和设计，不照抄本例作为授权。

## 目标与验收

- AC-01：当前有权访问的项目可收藏和取消；重复设定同一目标状态不产生重复关系或意外反转。
- AC-02：重新登录后仍能看到自己的收藏；不能读取其他用户的收藏。
- AC-03：权限被移除后，收藏不会让用户绕过项目可见性校验。
- AC-04：写入结果未知时不误报保存成功或已回滚；恢复显示有该操作结果与当前状态的依据，旧响应不覆盖后续有效操作。

本轮不做离线修改、收藏排序、共享列表或消息通知。修改范围为收藏行为、相关接口与 UI，以及必要测试；具体路径由实际项目约定。

## 关键设计与理由

收藏关系使用用户与项目组合的唯一约束；写入表达目标状态，而不是每调用一次就翻转。查询仍经过原有项目权限校验，避免收藏表成为另一份授权源。重复同一操作与用户发起新的相反操作需要区分，顺序与并发语义通过目标项目的契约明确。

Client 区分明确拒绝与结果未知。只有取得可信终态时才按约定协调显示；超时先保留未知，按已有协议查询同一操作并协调资源视图。若项目没有终态或顺序保证，就需要补设计或明确阻断 AC-04，不能凭一次读到旧状态宣称请求失败、直接重复写入或假称能力已存在。Server 的幂等、原子边界与权限检查需实际验证。

两端设计可在此说明，暂不拆 CLIENT-SDD / SERVER-SDD。接口字段引用实际项目可执行定义；本示例不编造仓库链接。取舍依据见 [超时与恢复规则](../docs/ENGINEERING_RULES.md#超时重试与结果未知)。

## 实施增量示意

| 增量 | 对应验收与可观察结果 | 真实依赖 |
|---|---|---|
| 收藏、保存后读取与最小界面 | AC-01 收藏部分、AC-02：同账户重新登录可见，其他账户不可见 | 已有身份/权限接口和持久化设施经核实 |
| 取消与结果未知的处理 | AC-01 取消部分、AC-04：取消后关系不存在；迟到响应不覆盖后续操作 | 上一片的写入/读取契约；操作结果与顺序语义明确 |
| 撤销权限后的完整行为核对 | AC-03：已收藏也不能越权读取；相关回归 | 原项目权限变更能力和实际收藏实现 |

第一片通过不能代表取消、超时和权限撤销已经通过。团队可将第三项检查提前或并入实现；表格不是固定派工顺序，支撑性工作与真实依赖按项目情况安排。

## 验证安排

下表都是待执行的检查计划。预期来自上述约定，不从实现结果反推；权限相关分支需要适当独立评审。

| 场景 | 可区分的错误 | 预期与观察位置 |
|---|---|---|
| 正常收藏、取消后重新读取 | 只改 UI 或取消未持久化 | 保存后可见、取消后关系不存在，实际 API 与界面读取共同支持 AC-01 |
| 重复设定收藏状态 | 重复行或错误翻转 | API/读取行为符合 AC-01；必要时核验实际数据库唯一约束 |
| 同账户重新登录、另一账户读取 | 只保存内存状态或越权 | 刷新/登录读取与可信身份校验支持 AC-02 |
| 已收藏后撤销访问权限 | 收藏绕过权限服务 | 列表及直接读取都遵守 AC-03，不能只测按钮隐藏 |
| 写入已提交但响应丢失，再有迟到响应或取消意图 | 超时即误报回滚、旧响应覆盖新意图 | 按已确定的故障时序核验操作结果和显示；缺可观察终态则 AC-04 未验证 |

## 评审与交付记录示意

假如计划要求直接信任请求中的账户，而本规格要求可信会话，评审应指出计划错误，按已确认身份规则修计划与实现并重验；不能因为实现符合计划就关闭越权意见。多次提交的同一增量提供完整差异，工作区尚未提交的内容也明确纳入审查范围。

如果实现已完成但还未验证权限撤销后的查询，应写明：“收藏主路径已实现；权限撤销行为尚未验证，AC-03 未确认，当前不能宣布任务完成。下一步补充该场景的实际测试与评审。”这句话只示范实际出现该情形时的写法。

当前示例没有执行代码或测试，也没有验收。实际结果在本文件或关联交付 PR 中择一汇总；不能将上表的预期、模拟措辞或审阅建议填成已通过。
